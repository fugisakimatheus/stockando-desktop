# Project Features and Capabilities

This document is the entry point for the product documentation for the desktop business system. It summarizes the main functional domains covered by the current database schema and the intended product scope.

## Scope Overview

The application is designed to support a multi-company retail and distribution workflow with the following capabilities:

- company and user administration
- customer and supplier management
- product catalog and inventory control
- sales quotes and orders
- purchasing workflows
- pricing and payments
- fiscal document management
- auditing and document attachments

## Product Principles

- company-centric design
- modular growth without breaking the existing foundation
- strong data integrity and auditability
- support for inventory, sales, purchasing, and fiscal operations
- extensibility for future integrations and reporting
