# Security Policy

## Reporting a vulnerability

Please report security issues privately and do not open a public issue for them.

Use the GitHub Security Advisory workflow if the repository is hosted on GitHub, or contact the maintainers through the project’s private communication channel.

## What to include

When reporting a vulnerability, include:

- a clear description of the issue
- the affected component or workflow
- steps to reproduce, if available
- any potential impact and severity assessment

## Response expectations

We will review reports as quickly as possible and aim to provide an initial response within a reasonable timeframe. If a fix is needed, we will coordinate a safe remediation plan and disclose the matter responsibly.
