# Project Language

## Documentation Language

- Write all project documentation in English.
- Use clear, natural English with consistent domain terminology.
- Name documentation files in lowercase kebab-case.
- Keep `README.md` in uppercase as the only exception.

## Chat and Interaction Language

- Write all chat and Copilot responses in Portuguese.
- Deliver technical explanations, code suggestions, and review comments in Portuguese, even when referencing English technical terms.
